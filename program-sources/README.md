# Program source files

Trimmed-text source material per catalog program, so later builders encode programs from these
files and never browse the web. Owner ruling 2026-09-26: when a department page and the Academic
Catalog disagree, the department page wins. One file per program, named `<program>.md` (the
catalog page's last URL path segment; the department segment is prefixed only when two programs'
keys would otherwise collide).

There are two kinds of file, told apart by the first line:

- **Generated** (`<!-- generated by fetch-sources.ts: do not hand-edit -->`): produced by
  `packages/catalog/scripts/fetch-sources.ts` from the cached catalog page plus whatever
  department/sample-plan URLs are recorded for that program in `sources.json`. Re-running the
  script overwrites these files; hand edits to a generated file will be lost on the next run --
  edit `sources.json` (or the department/sample-plan page itself) instead. Sections: "Catalog
  requirements", "Catalog four-year plan" (only if the catalog page has one), one "Department
  page (<url>)" per department source, one "Sample plan (<url>)" per sample-plan source. A source
  that couldn't be converted (a PDF fetch failure, a spreadsheet, a Google Docs/Sheets link) gets
  a one-line note instead of a body, and is also listed in `missing.md`.
- **Hand-captured** (e.g. `cmsc-major.md`, `ccjs-major.md`): pasted by the owner or a builder when
  the department page can't be fetched automatically, or to point at the right page. These have no
  generated-header marker, so `fetch-sources.ts` always skips them -- it will never overwrite a
  hand-captured file. The first lines give the source URL(s) (or "URL not given") and the date
  pasted/fetched.

`sources.json` is the department/department and sample-plan URL map keyed by program: `{ "<program>":
{ "catalog": url, "department": [urls], "samplePlan": [urls] } }`. `fetch-sources.ts --seed`
(re)builds it from each catalog page's overview and four-year-plan tab, but never overwrites an
entry that's already there, so hand edits (added URLs, corrections) survive a re-seed.

`missing.md` lists every program with no department URL, no sample-plan URL, a fetch failure, or
an unconverted source format -- also generated by `fetch-sources.ts`.
