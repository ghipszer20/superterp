# UMD degree audits (private)

The owner pastes UMD degree audit text here, one file per program, to verify SuperTerp's
requirement encodings against what UMD actually enforces. Everything in this folder except
this README is gitignored: audits contain personal academic records and never leave this machine.

- One plain-text file per audit, named after the program, e.g. `math-applied.txt`, `cmsc-major.txt`.
- For a program you're not in, run UMD's "what-if" audit for it and paste that.
- Paste the whole page as text (select all, copy, paste). Don't edit it.
