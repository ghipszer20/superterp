# The rules engine decides; the LLM only explains

Advising answers (what's missing, what to take, whether a plan works) come only from the deterministic rules engine, prerequisite graph and optimizer. The LLM receives their results through tool calls and turns them into plain language; it never states a requirement, prerequisite or deadline on its own. A fluent but invented requirement could cost a student a semester, and the owner has taken personal responsibility for verifying requirement data, which only works if the data, not a model, is what students see.
